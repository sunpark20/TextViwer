# 음성 텍스트 뷰어 테스트 가이드

## 준비사항

### 1. Flutter 설치 확인
```bash
flutter --version
```

Flutter가 없다면 [flutter.dev](https://flutter.dev)에서 설치하세요.

### 2. 프로젝트 설정
```bash
cd voice_text_viewer
flutter pub get
```

### 3. 연결된 디바이스 확인
```bash
flutter devices
```

## 테스트 방법

### 방법 1: Android 에뮬레이터
```bash
# Android Studio에서 에뮬레이터 실행 후
flutter run -d emulator-5554
```

### 방법 2: 실제 디바이스 (권장)
음성 인식은 실제 디바이스에서 더 잘 작동합니다!

```bash
# iOS (Mac만 가능)
flutter run -d ios

# Android
# USB 디버깅 활성화 후 연결
flutter run -d android
```

### 방법 3: Chrome (웹 테스트)
```bash
flutter run -d chrome
```
⚠️ 주의: 음성 인식이 브라우저에서 제한적일 수 있습니다.

## 테스트 시나리오

### 1단계: 앱 실행 확인
- [ ] 앱이 정상적으로 실행됨
- [ ] 홈 화면에 3개의 샘플 텍스트 카드가 보임
- [ ] 하단에 사용 방법 안내가 표시됨

### 2단계: 권한 확인
- [ ] "빠른 테스트" 선택
- [ ] 마이크 권한 요청 팝업이 나타남
- [ ] "허용" 클릭

### 3단계: 음성 인식 테스트
- [ ] 하단 마이크 버튼 클릭
- [ ] 버튼이 빨간색으로 변함 (듣는 중)
- [ ] "다음"이라고 말하기
- [ ] 상단에 "인식됨: 다음" 표시
- [ ] 페이지가 넘어감 ✅

### 4단계: 모든 명령어 테스트
- [ ] "다음" → 2페이지로
- [ ] "이전" → 1페이지로
- [ ] "끝" → 마지막 페이지로
- [ ] "처음" → 1페이지로

### 5단계: 영어 테스트
- [ ] 상단 언어 아이콘 클릭
- [ ] "English" 선택
- [ ] "next" → 다음 페이지
- [ ] "previous" → 이전 페이지

### 6단계: 수동 조작 테스트
- [ ] 화면을 좌우로 스와이프
- [ ] 페이지가 부드럽게 넘어감

## 문제 해결

### 음성 인식이 작동하지 않는 경우
1. 마이크 권한을 확인하세요
   - Android: 설정 > 앱 > 음성 텍스트 뷰어 > 권한 > 마이크 허용
   - iOS: 설정 > 개인정보 보호 > 마이크 > 앱 허용

2. 인터넷 연결을 확인하세요

3. 실제 디바이스를 사용하세요 (시뮬레이터는 제한적)

### 빌드 에러가 발생하는 경우
```bash
flutter clean
flutter pub get
flutter run
```

### iOS Pod 에러
```bash
cd ios
pod deintegrate
pod install
cd ..
flutter run
```

## 예상 결과

### 성공 시 보이는 것
- ✅ 음성 명령 후 페이지가 즉시 넘어감
- ✅ 인식된 텍스트가 화면 상단에 표시됨
- ✅ 페이지 번호가 업데이트됨 (예: 2 / 4)
- ✅ 부드러운 페이지 전환 애니메이션

### 소리가 잘 인식되지 않는 경우
- 조용한 환경에서 테스트
- 마이크에 가까이서 또렷하게 발음
- "다음 페이지" 대신 짧게 "다음"만 말하기
